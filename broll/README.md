# B-roll library

Drop clips here. Any format ffmpeg reads. Everything in this folder except this file is git-ignored.

Best clips are your own cinematic shots: typing, working on a project, desk and setup details, walking.
They make a reel feel shot, not generated.

- 3 to 15 seconds each, steady, in focus, one continuous shot (no cuts inside).
- Vertical or horizontal both work; clips are cropped to 9:16 around the centre.
- A clip is used at most once per reel.
