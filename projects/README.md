# Projects

One folder per reel, created by `npm run reel -- new <slug> <video>`. Everything here except this file is git-ignored.

```
source/       normalised footage and voice
assets/       captures, logos, b-roll, and ledger.json (where each came from)
transcript.*  word timings
edit.json     the edit plan
build/        resolved plan and audio stems
renders/      final.mp4
checks/       stills, cut strips, opening frames
```
